Contributing
------------

Contributions to libneo4j-omni are encouraged and should be made via pull
requests made to the [GitHub repository](
https://github.com/majensen/libneo4j-omni). Please include test cases where
possible, and use a style and approach consistent with what @cleishm
has used in the rest of the library.

It may be worthwhile raising an issue on github for the contribution you
intend to make before developing the code, to allow for discussion and feedback
on the requirements.

To have `make check` run the tests, [Check](https://libcheck.github.io/check/)
needs to be installed before running `configure`.


Project policy
--------------

-   **The libneo4j-omni software is maintained as-needed for personal projects only.**

    We do welcome contributions, but no maintainer currently feels
    responsible for regularly reviewing issues or pull requests.
    Commits and merges may still happen from time to time depending on
    maintainer interest.

-   **There is no security support for this software.**

    Should you find something that you believe is a vulnerability or has a
    security impact, please file it publicly by opening a regular GitHub issue.
    Such issues may or may not be treated with priority over other issues that
    aren’t security-related.

-   **Any use of LLMs or “GenAI” for contributions and discussions is prohibited.**

    The only possible exceptions are for human accessibility needs and for
    read-only code analysis, on condition that use of these tools is limited
    to a minimal extent *and* is always clearly identified.
    Under no circumstances whatsoever may content generated by Large Language
    Models or similar agents be merged into the code base.
